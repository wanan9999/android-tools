# android-tools

一个 Windows 上的安卓设备工具，支持连接手机、投屏、文件管理和 Fastboot 刷机。

## 开始使用

1. 在 [发布页面](https://github.com/wanan9999/android-tools/releases) 下载 Windows 版 ZIP 并解压。
2. 双击运行 `android-tools.exe`。请保留它旁边的 `android-tools` 文件夹。
3. 在手机的开发者选项中开启 USB 调试，用数据线连接，并在手机上允许调试。也可以打开应用的“无线连接”，按照提示配对。

需要 Windows 10 或 11 的 64 位系统。无线调试需要 Android 11 或更高版本，电脑和手机应连接同一局域网。

## 常用操作

- 在设备列表点击操作图标，可安装 APK、截图、重启或打开文件管理。文件管理支持拖入电脑上的普通文件上传、下载手机文件、重命名和删除。
- 点击投屏图标可显示手机画面；声音、画面尺寸、帧率和码率可在“应用设置”中调整，下次投屏时生效。
- Fastboot 设备可重启或刷写镜像。刷写前请确认设备型号、分区和镜像匹配；删除文件前请确认路径。
- 如果提示组件缺失，可在“应用设置”中点击组件检查图标。若组件已被修改，请退出应用并移走旧的 `android-tools` 文件夹，再重新下载。
- 在“应用设置”中可配置 HTTP 或 SOCKS5 代理，或使用 Windows 系统代理；留空时直连。闪电图标显示建立连接后访问 Google 测试地址的响应延迟，组件和驱动下载会显示进度。

设备记录和应用设置保存在 `%APPDATA%\android-tools\devices.json`。删除该文件会清除应用中的设备记录和设置。
